# Belagora: Interface Web (Frontend)

Interface web do **Belagora**, sistema ERP de gestão e agendamento de serviços de beleza baseado em geolocalização.

> Este repositório contém apenas o **frontend**. O sistema completo depende também da API:
> [belagora-api](https://github.com/thamidorville/belagora-api) (back-end em .NET 9).

## Stack

- React + TypeScript
- Vite
- React Router
- Axios

## Como rodar

```bash
npm install
npm run dev
```

A aplicação sobe em `http://localhost:5173` e consome a API do Belagora.
